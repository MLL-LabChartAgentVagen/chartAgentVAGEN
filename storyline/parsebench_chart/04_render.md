## 1. 单一插桩后端

**几何只有一个来源**：一个插桩过的 matplotlib 渲染器。它在绘制每个 mark 的同时记录该 mark 的框、键与值，产出 [05](05_provenance.md) 的 L1 层。

多后端会把项目最难的部分乘以后端数量——每加一个后端就要重写一遍 mark 抽取，且两套实现的坐标约定必须逐像素对齐。因此：

- 风格多样性来自**同一后端内的参数**、**渲染后的图像退化**、**页面合成**这三处，不来自换后端。
- 企业 BI 模板的观感（粗边框、投影、伪三维、低对比配色）在 matplotlib 内部实现，不引入新后端。
- 第二后端是可选扩展，只有当 [06 §4](06_output.md) 的风格消融显示后端差异确实影响真实基准迁移时才做。

**坐标约定**：像素坐标，原点在图像左上角，框记为 `[x0, y0, x1, y1]`，随图像宽高一并记录。全流水线只有这一套约定。

## 2. 风格向量

与 FigureSpec 正交采样，因此同一份 ground truth 有 N 个视觉版本，构成配对数据。按作用位置分三组。

### 2.1 渲染参数（后端内部）

| 维度 | 取值 |
|---|---|
| 数值标注 | 全画 / 全不画 / 部分画 |
| 版面 | 单图 / 网格面板 / 共享轴 / 外置共享图例 / 每面板独立图例 |
| 图表族 | 含 compound（同面板 bar + line 双轴） |
| 数字格式 | 千分位 / 货币符号 / 百分比 / K,M,B 后缀 / 括号负数 |
| 配色 | 企业 BI 低对比 / 同色系 / 渐变填充 / 灰度打印 |
| 图元风格 | 边框粗细 / 投影 / 伪三维 / 网格线 / 字体族与字号 / 条宽 / 填充纹理 |
| 轴 | 起点是否为零 / 刻度密度 / 标签旋转 / 对数轴 |

## 3. 图像退化

只允许几何变换已知的退化，框按同一变换映射，标注保持精确。

| 退化 | 几何变换 | 框如何处理 |
|---|---|---|
| JPEG 压缩 / 扫描噪声 / 模糊 | 恒等 | 不变 |
| 降采样 | 缩放 | 按比例缩放 |
| 轻微旋转 | 仿射 | 顶点变换后取外接框 |
| 透视形变 | 单应 | 顶点变换后取外接框 |

任何无法写出解析变换的退化不进入管线。

## 4. 页面合成

图表不直接输出为裸图像，而是嵌入一张含正文、页眉、页脚、表格的版面。

由此得到：

- 页面元素的 bbox 与类别标签，类别取自 `{Text, Table, Picture, Page-Header, Page-Footer}`，即 [05](05_provenance.md) 的 L0 层
- 非平凡的定位任务——裸图像中图表占满整幅画面，定位无信息量
- 单页多图、跨栏、图注与图表分离等真实版面现象，且可控

合成器把图表图像贴入页面时对 L1 的框施加一次平移与缩放，与 [§3](#3-图像退化) 用同一套变换机制。

## 5. 数值标注

单独提出，因为它决定 [06](06_output.md) 的容差：

| 标注状态 | 容差 |
|---|---|
| 图上画出了数值 | 0（精确匹配） |
| 图上未画数值 | 1% 相对容差，且须通过 [05 §4](05_provenance.md) 的可恢复性判定 |

同一份数据、同一个 FigureSpec 渲染两次——画标注与不画标注——ground truth 完全相同，构成配对消融。

**未通过可恢复性判定的点直接排除出值目标集**，不回头调整轴范围或补画标注。渲染是单向的一遍，不存在重渲染。被排除的 mark 仍然贡献 `(键, 区域)` 的定位目标。
