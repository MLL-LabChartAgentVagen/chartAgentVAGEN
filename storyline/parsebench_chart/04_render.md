# 04 · 渲染

FigureSpec + 独立采样的风格向量 → 页面图像。项目的工作量重心。

**本文**
1. [八个采样维度](#1-八个采样维度) → 2. [数值标注](#2-数值标注) → 3. [页面合成](#3-页面合成) → 4. [Chart Registry](#4-chart-registry)

## 1. 八个采样维度

| 维度 | 取值 | 工作量 |
|---|---|---|
| **数值标注** | 全画 / 全不画 / 部分画 | 小 |
| **版面** | 单图 / 网格面板 / 共享轴 / 外置共享图例 / 每面板独立图例 | 小 |
| **图表族** | 含 compound（同面板 bar + line 双轴） | 小 |
| **数字格式** | 千分位 / 货币符号 / 百分比 / K,M,B 后缀 / 括号负数 | 小 |
| **配色** | 企业 BI 低对比 / 同色系 / 渐变填充 / 灰度打印 | 中 |
| **渲染后端** | matplotlib / plotly / 企业模板（粗边框、投影、伪三维） | 中 |
| **图像退化** | JPEG 压缩 / 降采样 / 扫描噪声 / 轻微旋转与透视形变 | 中 |
| **页面合成** | 图表嵌入带正文、页眉、页脚、表格的版面 | 中 |

前四项是渲染器内部参数；后四项需要多后端支持、图像退化管线、版面排布器。

风格向量与 FigureSpec 正交采样，因此同一份 ground truth 有 N 个视觉版本，构成配对数据。

---

## 2. 数值标注

单独提出，因为它决定 [06](06_output.md) 的容差：

| 标注状态 | 容差 |
|---|---|
| 图上画出了数值 | 0（精确匹配） |
| 图上未画数值 | 1% 相对容差，且须通过 [03](03_figure.md) 的值可恢复性检查 |

同一份数据、同一个 FigureSpec 渲染两次——画标注与不画标注——ground truth 完全相同，构成配对消融。

## 3. 页面合成

图表不直接输出为裸图像，而是嵌入一张含正文、页眉、页脚、表格的版面。

由此得到：

- 页面元素的 bbox 与类别标签，类别取自 `{Text, Table, Picture, Page-Header, Page-Footer}`
- 非平凡的定位任务——裸图像中图表占满整幅画面，定位无信息量
- 单页多图、跨栏、图注与图表分离等真实版面现象，且可控

## 4. Chart Registry

6 族 16 型，每型定义结构要求、支持的数据模式、行数范围。

**必要扩展**

- **compound / 双轴**：同一面板内 bar 与 line 混合，左右两个纵轴。同一像素高度对应两个不同的值。
- **面板级属性**：面板共享关系（共享 x / 共享 y / 共享图例）的表达。

> 完整 registry 见 [`../data_generation/chart_type_registry.md`](../data_generation/chart_type_registry.md)。
