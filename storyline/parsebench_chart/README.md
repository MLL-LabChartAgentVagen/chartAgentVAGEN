# 带位置的图表转录 — 数据生成

程序化生成图表数据，产出的每个数值都带着它被画在哪里的坐标。目标能力是 **grounded transcription（带位置的转录）**：把图表转成结构化表的同时，给出每个值读取自哪块像素区域。

---

## 流水线

四个执行阶段，两份数据接口定义。

```
 01  场景        领域 → 场景描述 + 分析意图                        用 LLM
      ▼
 02  事实表      LLM 写数据生成程序 → 行级事件表 + 表结构说明        用 LLM 写程序
      ▼
 03  选图        枚举 → 规则过滤 → LLM 在候选中挑 → FigureSpec       用 LLM 做选择
      ▼
 04  渲染        独立采样风格 → 页面图像 + 标注记录                  不用 LLM
- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
 05  标注记录    三层记录的字段、值能否读出的判定、三项自检           数据接口
 06  输出        标注记录 → 训练目标                               数据接口
```

05 与 06 不是执行阶段：05 规定 04 产出的那份记录长什么样、必须通过哪些检查，06 规定怎么把记录变成训练目标。

## 贯穿示例

六个阶段文档末尾都有「示例」一节，用的是同一份数据，从场景一路走到训练目标。

**急诊科等待时间**——A 市三家医院急诊科 2024 上半年的就诊记录。

| | |
|---|---|
| 维度 | `hospital` 协和 / 华山 / 瑞金 → `department` 内科 / 外科 / 儿科 / 创伤；`severity` 轻 / 中 / 重（有序） |
| 时间 | `visit_date` 2024-01-01 至 2024-06-30，按天 |
| 测度 | `wait_minutes` 分钟（可加）、`cost` 元（可加）、`satisfaction` 1–5 分（不可加） |
| 一行 | 一次就诊。共 900 行 |
| 分析意图 | ① 哪家医院等待最久 ② 等待时间随时间怎么变 ③ 等待时间与满意度是否相关 |

跟着这份数据可以看到：层级维度怎么声明、不可加的测度怎么挡掉饼图、一个条形的框怎么算出来、值能不能从图上量出来。

## 不变式

1. **一行一件事** — 事实表每行是一次不可再分的事件；聚合只发生在 [03](03_figure.md) 的投影里。
2. **LLM 不生产数值** — LLM 只做两件事：写数据生成程序、在枚举出的选项中做选择。进入图表的每个数字都由引擎算出。
3. **标注零成本且精确** — 所有 ground truth 从渲染过程中直接记下来，不靠估计，也不靠人工标注。
4. **风格与真值分离** — ground truth 由 FigureSpec 决定，与风格无关。同一份 FigureSpec 可以渲染 N 个外观不同的版本，共享一份答案。
5. **单向流水线** — 每个阶段是"给定输入与随机种子就得到确定输出"，阶段之间没有回环，不存在重试后重新渲染。
6. **几何只有一个来源** — 只有一个渲染器产出像素坐标，全流水线只有一套坐标约定。

## 相对上一版的改动

| 改动 | 原设计 | 现设计 |
|---|---|---|
| 03 的三步顺序 | 枚举 → LLM 选择 → 过滤 | 枚举 → 过滤 → LLM 选择。LLM 只在候选清单里挑序号，挑不出不可行的图，取消"选完再验、验不过重选"的回环 |
| 语义适当性 | 由 LLM 判断"真人会不会画这张图" | 查表：测度可加性与维度有序性在 [02](02_fact_table.md) 声明，[03](03_figure.md) 只做匹配 |
| 值能否读出 | 在 03 预测，与 04 形成回环 | 移到渲染之后按实际像素几何判定，并按画法分类（角度、面积、颜色三种画法没有数值标注时一律读不出） |
| 记录的产出者 | 渲染器同时输出三层 | 各层由知道该信息的组件产出：投影器→L2，渲染器→L1，页面合成器→L0，最后做一次拼接 |
| 渲染后端 | matplotlib / plotly / 企业模板三选一 | 只有一个渲染器；风格差异来自它内部的参数、渲染后的图像退化、页面合成 |
| 图表类型 | 16 型平铺 | 6 族 18 型，按图元形状分三层交付，Tier 1 十二型覆盖五个族 |
| 正确性保证 | 未定义 | [05 §6](05_provenance.md) 三项自检：框内有没有东西、量出来的值对不对、换风格答案变不变 |
