# 带位置的图表转录 — 数据生成

程序化生成图表数据，产出的每个数值都带着它被画在哪里的坐标。目标能力是 **grounded transcription（带位置的转录）**：把图表转成结构化表的同时，给出每个值读取自哪块像素区域。

---

## 整条流水线只有一次 LLM 调用

```
 01  数据     [LLM ×1]  领域 → 场景散文 + 生成脚本 + 绑到列上的意图
              [规则]    执行脚本 → 900 行事实表；逐族判可画性；覆盖度与结构检查
      ▼
 02  选图     [规则]    构造意图图 → 推出多面板图 → 按族采样轮转图 → 8 份 FigureSpec
      ▼
 03  渲染     [规则]    采样风格 → 边画边记 → 页面图像 + 几何
      ▼
 04  记录     [规则]    拼接三层 → 判定值能否读出 → 三项自检 → 标注记录
      ▼
 05  输出     [规则]    标注记录 → 8 类训练目标
```

那一次调用只产出**声明与绑定**，不产出任何数值。`[规则]` 是程序执行，给定输入与随机种子必得同样的输出。

进入图表的每个数字都由 01 的引擎算出，每个坐标都由 03 的渲染器记下。

**为什么是一次而不是两次**：脚本就是场景的形式化写法，意图指向的列就是脚本里的列。拆成"先写自然语言场景、再由第二次调用反解成列并重新绑定意图"，会在中间放一层有损的 JSON——层级关系、有序性、单位、可加性在自然语言里都不显式，反解只能靠猜，而下游没有回到上游的反馈通路。合成一次调用之后，绑定由构造成立。

## 贯穿示例

**急诊科等待时间**——A 市三家医院急诊科 2024 上半年的就诊记录。

| | |
|---|---|
| 维度 | `hospital` Mercy General / St. Luke's / Riverside → `department` Internal Medicine / Surgery / Pediatrics / Trauma；`severity` Minor / Moderate / Severe（ordinal） |
| 时间 | `visit_date` 2024-01-01 至 2024-06-30，按天 |
| 测度 | `wait_minutes` minutes（可加）、`cost` USD（可加）、`satisfaction` 1–5 points（不可加） |
| 一行 | 一次就诊。共 900 行 |
| 分析意图 | ① 哪家医院等待最久 ② 等待时间随时间怎么变 ③ 等待时间与满意度是否相关 |

一次运行的产物：900 行事实表 → 8 份 FigureSpec → 8 张页面图像 → 8 份标注记录 → 8 组训练目标。

这 8 张图分三类，产出方式各不相同——[详见 02](02_figure.md)：

| 类别 | 怎么产出 | 本例 | 它的价值 |
|---|---|---|---|
| **意图图** | 从意图绑定**直接构造**，不搜索 | 3 张 | caption 含有图像里读不出的信息 |
| **多面板图** | 以意图图为锚点，第二个面板由关系规则**推出来** | 2 张 | 共享图例的版面形态；与意图图构成配对样本 |
| **轮转图** | 按图表族**采样 + 拒绝**，收到干或到预算 | 3 张 | 图表类型覆盖面 |

**只有轮转图那一路需要随机数。** 一个场景实际出几张图是采样结果，不是配置里写死的数。

## 不变式

1. **一行一件事** — 事实表每行是一次不可再分的事件；聚合只发生在 [02](02_figure.md) 的投影里。
2. **LLM 不生产数值** — LLM 只做一件事：写一段声明脚本和一组意图绑定。
3. **可行性是查表，不是判断** — 哪些族能画由列声明决定，[01](01_data.md#6-覆盖度检查) 在生成数据之前就能算出来。
4. **标注零成本且精确** — 所有 ground truth 从渲染过程中直接记下来，不靠估计，也不靠人工标注。
5. **风格与真值分离** — ground truth 由 FigureSpec 决定，与风格无关。同一份 FigureSpec 渲染 N 个外观不同的版本，共享一份答案。
6. **单向流水线** — 阶段之间没有回环。一份 FigureSpec 配一份风格向量只画一次，判定不通过就少产出一个值目标，不调参重画。
7. **几何只有一个来源** — 只有一个渲染器产出像素坐标，全流水线只有一套坐标约定。
8. **元数据一次产出，多次投影** — 训练目标、问答对、风格配对、图表代码都是同一份记录的不同导出函数。
9. **LLM 只在"定义"时出现，不在"选择"时出现** — 01 写的是族与目标列，此后构造、采样、拒绝、组版全部是规则。意图图的族反映模型偏好，类型覆盖面由轮转图保证，见 [01 §3](01_data.md#意图把图表类型确定到什么程度)。
10. **多样性由判据管，不由数量管** — 批次里不允许出现两张 `(键集合, 图元形状)` 相同的图。数量上限只是预算，见 [02 §3.3](02_figure.md#33-预算与多样性是两回事)。
11. **带位置的输出能自己验自己** — 区域里有没有东西、区域几何配不配这个值，两项不需要 ground truth 就能查。生成期的自检代码原样用作训练期的可验证奖励，见 [05 §3](05_output.md#3-输出能自己验自己)。
