## 1. 输出格式

模型的输出单位是 **`(键, 值, 区域)`** —— 抽取每个值的同时给出读取它的像素区域。

它对既有任务优雅降级：

| 丢掉 | 得到 | 对应基准 |
|---|---|---|
| 区域 | `(键, 值)` | chart-to-table |
| 值 | `(键, 区域)` | chart grounding |
| 都保留 | grounded transcription | 目标能力 |

L2 在此基础上增加一列：`(键, 值, 区域, 行数)`。

grounded 输出**自验证**：区域内没有 mark、或区域的像素几何与声称的值矛盾，都能在无 ground truth 的条件下检出，可直接用作强化学习的可验证奖励。这与 [05 §8](05_provenance.md) 的前两项校验是同一个计算，一处实现两处使用。

## 2. 训练目标

| 目标 | 依赖层 | 内容 |
|---|---|---|
| grounded 表 | L1 | 所有 mark 的 (键, 值, 区域) 全集 |
| spot-check 标注集 | L1 | ≤10 个点，取自可恢复的 mark；画了标注则容差 0，否则 1% |
| 页面元素框 | L0 | bbox + 类别 |
| mark 定位 | L1 | 数据描述 → 区域。所有 mark 都可用，含不可恢复的 |
| mark 读值 | L1 | 区域 → 值。仅可恢复的 mark |
| 图例绑定 | L1 | 图例项 → 适用面板集合 |
| drill-down | L2 | 数据描述 → 聚合行数 |
| caption | — | 由 [01](01_scenario.md) 的场景与分析意图得到 |

可恢复性由 [05 §7](05_provenance.md) 逐 mark 判定并写在记录里，本阶段只做筛选。

## 3. 数据构成

合成负责 grounding、溯源、风格配对；真实图表负责风格分布。不做纯合成——合成与真实的风格差距是对任何纯合成工作的既定反对意见。

真实图表没有 `(值, 区域)` 配对标注，因此**只参与其标注支持的目标**：

| 来源 | 可参与的目标 |
|---|---|
| 本流水线合成 | 全部八项 |
| 真实图表（现有 chart-to-table 数据集） | grounded 表的 `(键, 值)` 部分、caption |
| 真实文档版面（现有版面数据集） | 页面元素框 |

混合比例是一个超参数，在 [§5](#5-消融) 的风格消融中一并测。

## 4. 评测

**主目标**

| 基准 | 维度 | 当前水平 |
|---|---|---|
| ParseBench | Charts（`ChartDataPointMatch`） | 最好 78.1%；多数专用 parser < 6% |
| ParseBench | Visual Grounding（Element Pass Rate） | layout-aware 流水线 70–81%；纯 VLM 6–7% |
| ChartREG++ | point / bbox F1 | 最好 < 50% |
| ChartAB | grounding & dense alignment | — |
| LongChart VQA | grounding / pointing | 要求输出 bbox 时最好模型 85.5% → 57.6%，所有模型 mDIoU 为负 |

**边界条件**（要求不退化）：CharXiv-Reasoning、ChartQAPro

**鲁棒性**（检验风格向量）：CHART NOISe 扰动集

## 5. 消融

| 消融 | 检验什么 |
|---|---|
| 去掉区域输出，只训表 | **主张的失败判据**。若加上区域后数值精度低于对照，主张不成立 |
| 关掉 L2 | 原子粒度是否有实验支撑。若 grounding 指标不变，则在论文中降级 |
| 固定风格向量 | 风格多样性对真实基准迁移的贡献 |
| 全部画数值标注 | 像素几何估读能力的贡献 |
| 去掉真实图表 | 合成-真实风格差距的实际影响 |

---

## 6. 主张

> Grounded transcription——抽取每个值的同时给出读取它的区域——可以由单个 VLM 完成，而其训练数据只能由渲染时插桩产生：大规模的 (值, 区域) 配对无法通过标注真实图表获得。这样训练的模型在 chart-to-table 上持平专用 parser，同时达到 layout-aware 流水线级别的视觉 grounding。

现状是没有任何单一方法在这两项上同时强：商业多阶段流水线两项均高，纯 VLM 在 grounding 上是个位数。
