# 03 · 渲染

把 FigureSpec 画成页面图像，同时把画的过程记下来。项目的工作量重心。

**这一阶段全部由程序执行，不调用 LLM。**

**子阶段**

| # | 子阶段 | 谁做 | 产出 |
|---|---|---|---|
| [3](#3-风格向量) | 采样风格向量 | 规则 | 一组风格取值 |
| [1](#1-边画边记) | 逐面板绘制，边画边记 | 规则 | 图元的框、键、值；面板与轴的值域像素域 |
| [4](#4-图像退化) | 图像退化，框同步变换 | 规则 | 退化后的图像与框 |
| [5](#5-页面合成) | 贴进页面版面 | 规则 | 页面图像 + 页面元素的框与类别 |

参考：[2 只有一个渲染器](#2-只有一个渲染器) · [6 数值标注](#6-数值标注)

先看 [§0 示例](#0-示例)，只看那一节就能明白这个阶段在干什么。

## 0. 示例

输入是 [02](02_figure.md#0-示例) 意图①的 FigureSpec：单面板 bar，三个条，值 42.3 / 35.8 / 28.1 分钟。

### 第一步 · 采样风格

风格与 FigureSpec 正交，独立按种子采样。同一份 FigureSpec 配不同风格，得到外观不同、答案相同的图。

```
数值标注  全不画            配色    企业报表低对比（三条同色系蓝）
轴        y 起点为零，刻度每 10 分钟     版面    单图
图像      900 × 600         退化    JPEG 质量 75
页面      嵌入单栏版面，图表居中，上方一段正文，下方图注
```

### 第二步 · 画图，同时记下位置

布局参数写死，不用自动布局：

```
绘图区  [96, 60, 860, 520]      宽 764，高 460
y 轴    值域 [0, 60] 分钟  ↔  像素域 520（值 0）→ 60（值 60）
```

每画一个条，就用 `y_px = 520 − 值 / 60 × 460` 算出它的位置并写进记录：

| 条 | 值 | 条顶像素 | 框 |
|---|---|---|---|
| 协和 | 42.3 | 520 − 324 = 196 | `[168, 196, 278, 520]` |
| 华山 | 35.8 | 520 − 275 = 245 | `[423, 245, 533, 520]` |
| 瑞金 | 28.1 | 520 − 215 = 305 | `[678, 305, 788, 520]` |

框、键、值三者在画的那一刻同时写下，不是画完之后再回头解析图像。

### 第三步 · 退化与页面合成，框跟着变

JPEG 压缩是恒等变换，框不变。页面合成把图表缩放 0.8 倍贴到 `(120, 340)`，三个框各自过一遍同样的平移加缩放。

### 输出

一张页面图像，加一份几何记录：三个条的框与值、绘图区与轴的值域像素域、页面上正文与图注的框。这就是 [04](04_record.md) 的 L1 与 L0 两层。

## 1. 边画边记

渲染器每画一个图元，就在同一处把它的**框、键、值**写进记录。框由绘图库自己的坐标变换算出：数据坐标 →（轴变换）→ 像素坐标。

不做"先画完图，再回头解析图像里有哪些图形"。只有在画的那一刻，框、键、值三者才同时在手；事后解析要重新把像素和数据对应起来，而这正是要消除的误差来源。

每种图表类型画出什么形状的图元、每个图元记哪几个值，见 [chart_types.md §3](chart_types.md)。

**坐标约定**：像素坐标，原点在图像左上角，框写成 `[x0, y0, x1, y1]`，随图像宽高一并记录。全流水线只有这一套约定。

**布局参数冻结**：图像尺寸、dpi、绘图区矩形三项写死。自动布局会在画完之后挪动绘图区，此时已经记下的框全部失效，而且不报错。

---

## 2. 只有一个渲染器

几何只有一个来源：一个 matplotlib 渲染器。

多个后端会把项目最难的部分乘以后端数量——每加一个就要重写一遍图元记录，两套实现的坐标约定还必须逐像素对齐。因此：

- 风格差异来自**渲染器内部的参数**、**渲染后的图像退化**、**页面合成**这三处，不来自换后端。
- 企业报表的观感（粗边框、投影、伪三维、低对比配色）在 matplotlib 内部实现。
- 第二个后端是可选扩展，只有当 [05 §7](05_output.md#7-消融) 的风格消融显示后端差异确实影响真实基准上的表现时才做。

## 3. 风格向量

**[规则]** 每个维度独立按种子采样，不做联合分布。风格向量随记录一起存，供消融时按维度分组。

| 维度 | 取值 |
|---|---|
| 数值标注 | 全画 / 全不画 / 部分画 |
| 版面细节 | 图例外置还是每面板一个 / 面板间距 / 共享轴是否重复画刻度 |
| 多面板类型 | 各面板同类型（small multiples）/ 混类型（如 bar + line） |
| 数字格式 | 千分位 / 货币符号 / 百分比 / K,M,B 后缀 / 括号负数 |
| 配色 | 企业报表低对比 / 同色系 / 渐变填充 / 灰度打印 |
| 图形细节 | 边框粗细 / 投影 / 伪三维 / 网格线 / 字体与字号 / 条宽 / 填充纹理 / 饼图是否中空 |
| 轴 | 起点是否为零 / 刻度密度 / 标签旋转 / 对数轴 |

**同一套条件的视觉变体归风格，不归类型表。** 中空的饼（donut）与实心的饼的四类条件逐格相同、图元形状相同、值字典相同，因此它是「图形细节」里的一个取值，不是 [chart_types.md](chart_types.md) 里的一行。新的视觉变体照此处理。

**版面的分工**：哪些视图进同一张图、彼此什么关系、共享哪条轴，由 [02](02_figure.md#5-figurespec) 的 FigureSpec 决定；风格只管视觉细节。各面板同类型还是混类型是风格维度，但**共享图例要求各面板共用同一个系列列**，这条是 FigureSpec 的硬约束，风格改不动，见 [02 §4.2](02_figure.md#42-共享图例的硬约束)。多面板图逐面板绘制，每个面板各自记一份框与轴的值域像素域，图元的 `panel_id` 指向它所在的面板。

轴起点是否为零直接改变值与像素的换算关系，因而影响 [04 §5](04_record.md#5-值能不能读出) 的判定结果——这是风格影响标注集大小、但不影响标注内容的唯一途径。

## 4. 图像退化

只允许几何变换写得出解析式的退化，框按同一个变换映射，标注保持精确。

| 退化 | 几何变换 | 框怎么处理 |
|---|---|---|
| JPEG 压缩 / 扫描噪声 / 模糊 | 恒等 | 不变 |
| 降采样 | 缩放 | 按比例缩放 |
| 轻微旋转 | 仿射 | 四个顶点变换后取外接框 |
| 透视形变 | 单应 | 四个顶点变换后取外接框 |

写不出解析变换的退化不进管线。旋转与透视之后外接框会比原图元略大，这是已知且可控的偏差，记录里注明施加过哪个变换。

---

## 5. 页面合成

图表不直接输出为裸图像，而是嵌进一张含正文、页眉、页脚、表格的版面。

由此得到：

- 页面元素的框与类别标签，类别取自 `{Text, Table, Picture, Page-Header, Page-Footer}`，即 [04](04_record.md) 的 L0 层
- 非平凡的定位任务——裸图像里图表占满整幅画面，定位没有信息量
- 单页多图、跨栏、图注与图表分开这些真实版面现象，且可控

合成器把图表贴进页面时，对已记录的框施加一次平移加缩放，用的是与 [§4](#4-图像退化) 相同的变换机制。

---

## 6. 数值标注

单独提出来，因为它决定 [05](05_output.md) 的容差：

| 标注状态 | 容差 |
|---|---|
| 图上写出了数值 | 0，要求精确匹配 |
| 图上没写数值 | 1% 相对容差，且要通过 [04 §5](04_record.md#5-值能不能读出) 的判定 |

渲染器只负责记下每个图元的 `labeled` 与标注框；判定值能不能量出来是 [04](04_record.md) 的事，判据只在 [chart_types.md §4](chart_types.md) 定义一次。

**渲染不回头。** 一份 FigureSpec 配一份风格向量只画一次：判定不通过的点直接从值目标里去掉，不调轴范围，不补画标注，不重画。被去掉的图元仍然贡献"键 + 区域"的定位目标。

同一份 FigureSpec 配**不同**的风格向量各画一次是另一回事：它是[风格配对样本](05_output.md#4-同一份记录还能派生什么)，也是 [04 §6](04_record.md#6-三项自检) 第三项自检的输入。两份记录的键与值必须完全相同。
