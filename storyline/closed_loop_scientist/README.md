# Closed-Loop AI Scientist on Verifiable Synthetic Worlds

> **一句话**:一个 **VLM agent** 在程序生成的世界里**主动探索**(请求图像、查表、做检验),提出机制假说、验证,最终交出一段**可执行的生成程序**;生成这个世界的原始程序就是 deterministic oracle,直接判定发现对不对——使"科学发现"第一次可被严格评估。世界由现有 data generation pipeline 产出,难度天然分级递进。
