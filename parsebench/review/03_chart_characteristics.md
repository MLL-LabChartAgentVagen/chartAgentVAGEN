§1–§3 的数字来自全部 4,864 条标注与 568 页，由 `tools/chart_split_stats.py` 算出。§4–§6 来自逐页查看的 5 张代表页，页面标识写在每条旁；**5 页不足以支撑对全集的比例判断**，比例待 [05 分析设计](05_analysis_design.md) 的 profile 通路补齐。

## 3. 三键索引

`3d_chart` 的官方说明是 "3D chart rendering"，但被标记的页面上没有透视渲染的图表。实际含义是**定位一个值需要三个键**：

| | 1 标签 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|
| 有 `3d_chart` | 0 | 46 | **633** | 24 |
| 无 | 268 | **3,801** | 82 | 10 |

两个实例：

```
She-figures_p115                value='61'   labels=['EU-27','Women','Researchers']
                                横向堆叠条，键 = 国家 × 性别 × 职业。平面绘制。
2023-05-sigma-01-english_p24    value='9.1%' labels=['US','2022:06','Inflation']
                                两面板折线，键 = 面板 × 时间点 × 系列。
```

标签按文档级施加，所以同页的二键图表也带上这个标记——上例第二页里 Figure 16 的 `labels=['2011','Direct']` 只有两个键，同样带 `3d_chart`。

三键在宽表里需要 colspan 表头才判得上关联，在长表里不需要（[02 §2](02_chart_metric.md#长表根本不会走到第四步)）。

## 4. 版面形态

| 现象 | 实例 |
|---|---|
| 输入是整页：正文、页眉页脚、图号标题、note、source 行 | 全部 5 页 |
| 一页多张独立图表，各自有图号，抽查点横跨它们 | `2023-05-sigma-01-english_p24`（Figure 16 + 17） |
| 一张图内左右两面板，量纲不同（计数 vs 百分比） | `05021ff2-en_p19` |
| 小倍数版面，6 面板各自带图例，面板名充当标签 | `(Web_version)_E-Government_Survey_2024_1392024_p101` |
| 两面板共享系列定义与图例结构 | `2023-05-sigma-01-english_p24` Figure 17 |

图号与图标题位于图之上、图表之外——正是 [02 §2 第四步](02_chart_metric.md#2-四步判定走一遍这条规则)上下文回退的对象。

## 5. 视觉多样性

| 特征 | 实例 |
|---|---|
| 无纵轴线，只有水平网格线 | `05021ff2-en_p19`、`2023-05-sigma-01-english_p24` |
| 面板整体带浅色底 | `2023-05-sigma-01-english_p24` |
| 图例底部色块无边框 / 顶部且含实线与虚线参考线两类 | `P505350-..._p49` / `..._p101` |
| 水平虚线参考线，带独立图例项 | `2023-05-sigma-01-english_p24` Fig 16 |
| 数值标签写在条内（白字）/ 分段内小字 / 窄段移到外部带引线 | `..._p101` / `P505350-..._p49` |
| x 刻度标签整体旋转 90° | `2023-05-sigma-01-english_p24` Fig 17 |
| x 轴两级标签（年在内，分组名在外，带分隔线） | `P505350-..._p49` |
| 分叉条形图，零线居中，含负值 | `05021ff2-en_p19` 右面板 |
| 堆叠条与分组条同图 | `P505350-..._p49` |
| 类目轴为 ISO 国家码，纵向排布 | `She-figures_p115` |

**稠密度跨度**：`05021ff2-en_p19` 左面板 10 根堆叠条 → `2023-05-sigma-01-english_p24` Fig 17 单面板 49 刻度 × 3 折线 → `She-figures_p115` 44 类目 × 2 子行 × 4 分段 = 352 个分段。我们当前的结构条件（`stacked_bar` 上限 20 格）画不到这一档，见 [04 P5](04_pipeline_gap.md#p5--稠密度上限抬高把稠密度变成一个可控自变量)。
